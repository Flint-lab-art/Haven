# test-plan — 二期测试补齐

> 本文件回答：二期要补哪些测试、补到什么程度、完成标准是什么。
> 依赖：`../api.md`、`data-model.md`

## 一、为什么二期第一件事是补测试

二期的两个功能（回收站、历史版本）都会改动 `notes` 的写入与读取路径。当前状态是：

| 包 | 生产代码行数 | 包内测试文件 |
|---|---|---|
| `internal/auth` | 2412 | 有（1500 行） |
| `internal/audit` | 519 | 有 |
| `internal/folders` | 557 | **无** |
| `internal/notes` | 995 | **无** |
| `internal/portfolio` | 627 | **无** |
| `internal/search` | 318 | **无** |
| `internal/tags` | 349 | **无** |

集成测试集中在 `cmd/haven/*_test.go`（约 2758 行），覆盖了 CRUD 与跨用户隔离，但**包内没有任何纯函数层面的测试**。在没有回归网的情况下改 `notes`，回收站与历史版本都会变成“改一处、坏三处”。

## 三、目标：B 级

补测试分三个层次，二期选 **B**：

| 层级 | 内容 | 是否二期 |
|---|---|---|
| A | 只补纯函数单测 | **包含在 B 中** |
| **B** | **A + 每个领域的边界集成测试（含跨用户隔离、软删除后的不可见性）** | **二期目标** |
| C | 补齐到接近 `auth` 的覆盖率 | 不做 |

## 四、清单

### 4.1 纯函数单测（包内 `*_test.go`）

| 包 | 目标 | 要覆盖的边界 |
|---|---|---|
| `internal/search` | `escapeLike` | `%`、`_`、`\` 被转义；含通配符的输入按字面匹配；空字符串；中文与多字节 |
| `internal/notes` | `Preview` | 空串、恰好 200 rune、201 rune（带省略号）、含多字节字符时不按字节截断 |
| `internal/notes` | `sameFolder` | 两个 nil、nil 与值、相同值、不同值 |
| `internal/folders` | `isSelfOrDescendant` | 自身、直接子级、隔代子级、兄弟节点、无关节点；**必须能识别循环**（防止拖拽产生环） |
| `internal/folders` | `normalizeIcon` | 空、单 Emoji、16 rune 边界、17 rune、含换行 |
| `internal/tags` | 名称长度校验 | `MaxNameRunes`（64）边界：63 / 64 / 65；空格 trim 后为空；多字节按 rune 计数 |

### 4.2 边界集成测试（`cmd/haven`）

现有集成测试已覆盖正常路径，本期补**边界与回归**：

| 用例 | 断言 |
|---|---|
| 软删除后公开列表不可见 | 删除一篇 public 笔记后，`GET /api/public/notes` 与 `GET /api/public/notes/:id` 都查不到 |
| 软删除后公开搜索不可见 | `GET /api/public/search` 不返回已删笔记 |
| 软删除后私有搜索不可见 | `GET /api/search` 不返回已删笔记 |
| 软删除后按标签查不可见 | `GET /api/tags/:id/notes` 不返回已删笔记；`note_count` 不计已删 |
| 软删除后私有列表不可见 | `GET /api/notes` 不返回已删笔记 |
| 还原后重新可见 | 还原后上述所有接口重新出现该笔记 |
| 原文件夹已删时还原 | 删除文件夹后再还原笔记，笔记落在收件箱 |
| 回收站保留期 | 超过 30 天的记录在访问回收站时被清理 |
| 版本写入 | 标题/正文/文件夹/标签变化时产生版本；只改 `sort_order` 不产生 |
| 版本合并 | 5 分钟内的多次修改合并为一条 |
| 版本还原 | 还原后标题、正文、文件夹、标签与快照一致 |
| 跨用户隔离 | 另一个用户看不到、也还原不了回收站与版本 |

### 4.3 前端

| 用例 | 断言 |
|---|---|
| 回收站路由 | `/trash` 需要登录，未登录跳 `/login` |
| 侧边栏高亮 | 在 `/trash` 时对应导航项高亮、其他不高亮 |
| 删除文案 | 笔记删除确认框提示“可在回收站中还原”，文件夹删除仍是“不可恢复” |
| DIFF 计算 | 新增/删除/未变三类行被正确分类（纯函数单测） |

## 五、完成标准

F3 视为完成，需同时满足：

1. `go build ./...`、`go vet ./...` 通过；
2. **设置 `HAVEN_TEST_DB_DSN` 后** `go test ./...` 全部通过，且 `notes` / `tags` / `search` / `folders` 四个包不再显示 `[no test files]`；
3. `pnpm test` 与 `pnpm build` 通过；
4. 第四节表中的用例全部存在且通过。

## 六、不做的事

- 不追求覆盖率数字，不引入覆盖率阈值门禁；
- 不引入新的测试框架或 mock 库（沿用 `testing` + 真实 PostgreSQL）；
- 不为 `portfolio` 补包内单测（本期功能不涉及）。
