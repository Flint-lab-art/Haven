# 记账分类草案（两级）

一级 7 个支出 + 1 个收入 = 8 个；二级每类 5~7 个，共 44 条。
「其他 xx」保留：表示「知道大类、不知道细项」，与一级「其他」语义不同。

## 说明

- **还款放在「其他」的二级**：信用卡 / 花呗还款本质是账户间资金移动
  （储蓄卡余额↓、信用卡欠款↓），优先记**转账**，不计入收支统计；
  没有对应账户可记时，才用「其他 · 还款」这个支出分类兜底。
  真正转给他人的钱（借钱、还钱给人）记「其他 · 人情往来」。
- **订阅 / Token** 从一级降为「娱乐」的二级：它们是具体的消费对象，不是场景。
- 一级「其他」下的「其他支出」：表示连场景都不知道。
- 收入只有 1 个一级分类，是为了让「总收入」口径单一；细分靠二级。
