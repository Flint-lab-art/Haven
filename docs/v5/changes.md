## 一、五期范围

**主题：仪表盘（概览页）。**

私有域目前进入后直接是工作台（三栏编辑界面），没有一个「总览」的地方。本期新增 `/` 仪表盘，展示写作统计与近期动态，工作台挪到 `/notes`。

| 序 | 功能 | 说明 |
|---|---|---|
| **H1** | 统计接口 | `GET /api/stats`，一次返回笔记数、字数、公开数、本周新增、热力图数据 |
| **H2** | 仪表盘页面 | 统计卡片 + 写作热力图（近三个月）+ 最近编辑 |
| **H3** | 路由调整 | `/` 改为仪表盘，工作台挪到 `/notes`；侧边栏顶部新增「仪表盘」 |

开发顺序：**H1 → H2 → H3**。

不纳入五期：标签云、文件夹概况、回收站提示、写作目标、数据导出。

| # | 文件 / 节 | 变更类型 | 变更说明 | v5 落点 |
