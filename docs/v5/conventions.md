# conventions — 五期约定

> 本文件回答：五期相对前几期约定做了哪些补充。
> 依赖：`../v1/conventions.md`

覆盖规则见 `../README.md` 第二节。v1 第一至五节继续有效，本文件只写五期新增。

## 一、五期约定补充

1. **统计接口只读**：`GET /api/stats` 不写任何数据，不产生审计事件。
2. **统计数据不做缓存**：每次请求现算。单用户、数据量小，加缓存的收益不如失效逻辑的复杂度。
3. **统计口径统一排除回收站**：全部聚合带 `deleted_at IS NULL`，与笔记列表一致。
4. **热力图补零在后端完成**：前端拿到的是完整日期序列，不自己补空日期。
5. **首页只读**：不提供任何写入口（新建、编辑、删除都走工作台）。

## 二、禁令变更

### 2.1 解除的禁令

**本期未解除任何 v1 禁令。**

### 2.2 新增的禁令

- 首页不做可配置的模块开关（不做「自定义布局」）；
- 不做统计数据的定时快照与历史对比；
- 不在首页嵌入编辑器或列表操作。
