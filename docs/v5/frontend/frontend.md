# frontend — 五期仪表盘

> 本文件回答：首页放在哪个路由、侧边栏怎么改、三块内容长什么样。
> 依赖：`../v1/frontend/frontend.md`、`../v1/frontend/ui-design.md`、`../api.md`

覆盖规则见 `../../README.md` 第二节。v1 的路由表、全局状态、API 客户端约定继续有效。

## 一、路由调整（替换 v1 第四节相关行）

**私有域 `/` 不再是工作台，改为概览首页。**

| 路径 | 页面 | 备注 |
|---|---|---|
| `/` | **仪表盘** | 新增，只读 |
| `/notes` | 工作台（三栏编辑界面） | 从 `/` 迁移过来，内容不变 |
| `/notes/:id` | 笔记详情 / 编辑 | 不变 |
| 其余 | 不变 | — |

**规则**：

- 登录成功后默认跳 `/`（首页），不再直接进工作台；
- `/login?redirect=` 逻辑不变；
- 侧边栏「笔记」指向 `/notes`；
- 站内所有跳回「工作台」的地方改为 `name: 'workbench'`（其路径变为 `/notes`）。

## 二、侧边栏（扩展 v1 `ui-design.md` 第八节）

顶部新增「首页」入口，位于「浏览」分组标签**之上**：

```
┌──────────────┐
│ Haven    «   │  ← Logo + 折叠
│              │
│  📊 仪表盘    │  ← 新增，独立于「浏览」
│              │
│  浏览         │  ← 分组标签
│  📄 笔记      │
│  🔍 搜索      │
│  🏷 标签      │
│  🗂 作品集    │
│  🗑 回收站    │
│              │
│  K 账户       │
└──────────────┘
```

- 选中态与其他 `side-link` 一致；
- Mini 模式下只显示图标，tooltip 为「仪表盘」。

## 三、仪表盘内容

**只读页面**：不提供新建、编辑、删除入口。

页面宽度占满详情区（与回收站一致，不受 800px 阅读列宽限制）。

### 3.1 页面结构

```
仪表盘

┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│  128   │ │  4.2万 │ │   12   │ │   5    │
│  笔记   │ │  字    │ │  公开  │ │ 本周新建│
└────────┘ └────────┘ └────────┘ └────────┘

写作热力图
┌──────────────────────────────────┐
│  ····  ··■·  ····  ··■·  ····    │
│  ■·□·  □·□·  ■·□·  □·□·  ■·□·   │
│  …                               │
└──────────────────────────────────┘

最近编辑
· 某篇笔记                    3 小时前
· 另一篇                      昨天
· …
```

### 3.2 统计卡片

| 项 | 规格 |
|---|---|
| 布局 | 四列等宽网格，间距 12px；窄屏两列、单列 |
| 容器 | 背景 `var(--fill-3)`，1px `var(--sep)` 边框，圆角 12px |
| 数字 | 26px / 字重 700 / `var(--label)`，千分位用逗号 |
| 标签 | 13px / `var(--label-2)` |

四张卡片固定为：**笔记数、总字数、公开数、本周新建**。

**大字缩写**：总字数超过 10000 时显示为 `4.2 万`，否则显示原数字。

### 3.3 写作热力图

- **范围**：近三个月（13 周），列 = 周，行 = 星期（一至日）；
- **格子**：宽度随容器平分，`aspect-ratio: 1` 保持正方形；间距 3px，圆角 2px；
- **色阶**（按当天编辑次数）：

| 次数 | 颜色 |
|---|---|
| 0 | `var(--fill)` |
| 1 | `color-mix(in srgb, var(--accent) 30%, var(--fill))` |
| 2 | `color-mix(in srgb, var(--accent) 55%, var(--fill))` |
| 3–4 | `color-mix(in srgb, var(--accent) 78%, var(--fill))` |
| 5+ | `var(--accent)` |

- **悬停**：tooltip 显示「2026-11-01 · 编辑 3 篇」；
- **左下角**：少量「少」→ 多量「多」的图例；
- **月份标签**：每列顶部标注月份，同一月份只标一次；
- 颜色一律用语义变量与 accent 混色，浅色与深色主题下都成立。

### 3.4 最近编辑

- 固定 5 条，来自 `recent` 字段；
- 每行：标题 + 相对时间（`formatRelative`）；
- 点击跳 `/notes/:id`（工作台）；
- 悬停标题变 `var(--accent)`。

### 3.5 空状态

- 一篇笔记都没有时：仍显示四张统计卡片（全为 0），热力图全空，最近编辑显示「还没有笔记」；
- **不隐藏任何模块**，保持版式稳定。

## 四、加载与错误

- 加载中：四张卡片显示骨架屏，热力图显示空白格子；
- 请求失败：在页面顶部显示一条错误提示 + 「重试」按钮，不清空已加载的数据。

## 五、不做的事

- 不做自定义布局或模块开关；
- 不做数据导出；
- 不做写作目标与提醒；
- 不在首页放编辑器或笔记列表操作。
