# api — 四期接口与配置

> 本文件回答：图片上传的配置项、静态托管规则与接口契约（v1–v3 未覆盖的部分）。
> 依赖：`../v1/api.md`、`../v1/architecture.md`

覆盖规则见 `../README.md` 第二节。通用约定（错误响应、鉴权标注）沿用 `v1/api.md` 第一章。

## 一、配置项

| 变量名 | 必填 | 说明 | 默认值 |
|---|---|---|---|
| `HAVEN_UPLOAD_DIR` | 否 | 上传文件的根目录（绝对路径或相对工作目录） | `./uploads` |

**规则**：

- 目录不存在时**启动即创建**（`os.MkdirAll`，权限 0755）；
- 创建失败拒绝启动，不静默降级；
- 生产环境由 `deploy.sh` 预先创建并设属主（见 `conventions.md` 第三节）。

## 二、静态托管

**`GET /uploads/*filepath`**：匿名可访问，返回磁盘上的文件。

| 项 | 规则 |
|---|---|
| 缓存 | `Cache-Control: public, max-age=31536000, immutable`（文件名含随机串，不会复用） |
| 路径安全 | 拒绝含 `..` 的路径，防止穿越到上传目录之外 |
| 未命中 | 返回 404，**不回退到 SPA** |
| 鉴权 | **不鉴权**：图片在公开笔记里也要能被匿名访问 |

## 三、上传接口

### 3.1 POST `/api/uploads`

**鉴权**：登录 + write（`read` Token 返回 403）

**查询参数**：

| 参数 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `kind` | `note` / `icon` | `note` | 决定文件落在 `notes/` 还是 `icons/` 下 |

**请求**：`multipart/form-data`，字段名 `file`，单个文件。

**允许的 MIME 类型**：

| 扩展名 | MIME |
|---|---|
| `.png` | `image/png` |
| `.jpg` / `.jpeg` | `image/jpeg` |
| `.gif` | `image/gif` |
| `.webp` | `image/webp` |

**不接受 SVG**（隐患见 `conventions.md` 2.2）。

**大小上限**：10 MiB。超过返回 413。

**响应** `201`：

```json
{
  "url": "/uploads/2026/11/8f3a1c9d2b.png",
  "name": "screenshot.png",
  "size": 48213,
  "mime": "image/png"
}
```

- `url` 是**相对路径**，前端直接拼进 Markdown；
- `name` 是客户端原文件名，仅供展示（不参与存储）；
- 文件按 `<kind 目录>/<年>/<月>/<16 字节随机十六进制>.<扩展名>` 存放：

| `kind` | 目录 | 示例 URL |
|---|---|---|
| `note` | `notes/` | `/uploads/notes/2026/11/8f3a1c9d2b.png` |
| `icon` | `icons/` | `/uploads/icons/2026/11/5e7b2d4a1c.png` |

**为什么分目录**：笔记插图与文件夹图标用途不同，混在一起会让图标选择列表出现笔记截图，也无法按用途清理。

**错误**：

| 状态 | 场景 |
|---|---|
| `400 bad_request` | 不是 multipart、缺少 `file` 字段 |
| `413 payload_too_large` | 超过 10 MiB |
| `415 unsupported_media_type` | 类型不在允许列表 |
| `422 validation_failed` | 文件为空，或 `kind` 不是 note / icon |

**说明**：

- **扩展名由服务端按 MIME 决定**，不采信客户端的文件名后缀；
- **不校验图片内容**（不解析像素），只信任 Content-Type 与文件头魔数是否一致；
- 上传成功后**不登记到数据库**：图片与笔记的关联完全靠正文里的 URL。

## 四、列出已上传的图片

### 4.1 GET `/api/uploads`

**鉴权**：登录

**说明**：列出 `icons/` 下的图片，供文件夹图标选择时复用。数据直接来自磁盘，**不经过数据库**。

**不列 `notes/`**：笔记正文里的插图与图标用途无关，列出来只会干扰选择。

**查询参数**：

- `limit`：可选，默认 60，最大 200；
- 按文件修改时间倒序（最近上传的在前）。

**响应** `200`：

```json
{
  "items": [
    { "url": "/uploads/2026/11/8f3a1c9d2b.png", "size": 48213, "created_at": "2026-11-01T10:22:00Z" }
  ],
  "total": 12
}
```

**规则**：

- 只列出允许的扩展名（png / jpeg / gif / webp），忽略 `.part` 等临时文件；
- 递归扫描 `icons/<年>/<月>/`；目录不存在时返回空列表；
- **无分页游标**：单用户场景文件量小，一次取前 N 条即可；
- 磁盘上的文件被手动删除后，下次调用自然消失（不做一致性检查）。

**错误**：

- `500 internal_error` — 上传目录不可读。

## 五、不做的事

- 不提供删除上传文件的接口（孤儿文件保留，见 `conventions.md` 第一节第 5 条）；
- 不提供独立的图片管理页面（列表只服务于图标选择）；
- 不做图片压缩、转码、缩略图；
- 不接收非图片文件。
