# conventions — 三期约定与禁令变更

> 本文件回答：三期相对前两期约定做了哪些补充，以及哪些规则被放宽、哪些仍是硬约束。
> 依赖：`../v1/conventions.md`、`../v2/conventions.md`

覆盖规则见 `../README.md` 第二节。v1 第一、二、三、五节与 v2 第一节继续有效，本文件只写三期新增与变更。

## 一、三期约定补充

1. **三期以公开域前端为主**。作品详情需要介绍正文，因此额外新增了 `portfolio_items.content` 字段与一个公开详情接口（见 `api.md`），这是对原「不改后端」计划的扩展，已登记在 `changes.md`。除此外不改后端。
2. **首页数据复用现有接口**：`GET /api/public/notes` 与 `GET /api/public/portfolio`，两者都返回 `total`，用于判断是否显示「全部」链接。作品详情单独调 `GET /api/public/portfolio/:id`。
3. **条数是代码常量**，写在页面组件内，不进文档、不进环境变量：
   - 首页作品数上限 `4`；
   - 首页笔记数上限 `5`；
   - 「全部」链接仅在 `total > 上限` 时显示。
4. **公开域仍然无登录入口、无任何写操作入口**（v1 禁令继续有效）。
5. **搜索页保留但不再有首页入口**：`/search` 路由与页面保留，首页移除搜索框。直接输入 `/search?q=` 仍可用。

## 二、禁令变更

### 2.1 放宽的约束

| v1 条目 | 三期处理 |
|---|---|
| `v1/frontend/ui-design.md` 第二节「正文列宽上限 800px」 | **公开域放宽到 960px**；私有域三栏布局与 800px 阅读列宽**不变** |
| `v1/frontend/ui-design.md` 第十节「公开域笔记列表排版规范」 | 记录结构（日期 → 标题 → 摘要）保留；间距、字号、区块分隔方式按 v3 规格调整 |
| `v1/frontend/ui-design.md` 「平铺列表，不用浮动卡片、阴影」 | **公开域作品集允许使用卡片**：浅色底 + 1px 边框 + 圆角，hover 时边框变色与轻微位移。私有域仍保持平铺风格 |

### 2.2 仍然有效的禁令

- 不做 SSR / Nuxt / 预渲染，公开域仍是纯 Vue 3 + Vite SPA；
- 不为 SEO 做任何专门优化（不加 meta 动态注入、不做预渲染、不做 sitemap）；
- 不引入组件库与 UI 框架，全部原生 CSS；
- 不引入第三方动画库；
- 公开域不暴露任何后台入口；
- 不自动抓取仓库 README（正文由使用者手动填写）；
- 不提供作品正文的版本历史。
