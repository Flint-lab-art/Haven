# frontend — 三期公开域改版

> 本文件回答：公开域首页改成什么样、新增哪些页面、视觉规格是什么（v1/v2 未覆盖的部分）。
> 依赖：`../v1/frontend/frontend.md`、`../v1/frontend/ui-design.md`、`../conventions.md`

覆盖规则见 `../../README.md` 第二节。v1 的私有域路由、登录流程、全局状态、API 客户端约定**继续有效**，本文件只写公开域的变更。

## 一、公开域路由（替换 v1 第三节）

**本节整节替换 v1 `frontend.md` 第三节的表与规则，以本文件为准。**

| 路径 | 页面 | 调用的接口 |
|---|---|---|
| `/` | 首页：品牌标语 + 作品集 + 近期笔记 | `GET /api/public/portfolio`、`GET /api/public/notes` |
| `/notes` | 全部公开笔记列表 | `GET /api/public/notes` |
| `/notes/:id` | 公开笔记详情 | `GET /api/public/notes/:id` |
| `/search?q=` | 公开搜索 | `GET /api/public/search` |
| `/portfolio` | 作品集（全部） | `GET /api/public/portfolio` |
| `/portfolio/:id` | 作品详情（含介绍正文） | `GET /api/public/portfolio/:id` |

**规则**：

- 公开域**仍然没有登录页、没有设置页、没有任何写操作入口**；
- 公开域**不暴露任何后台入口**，后台地址由使用者手动输入；
- 所有页面匿名可访问；
- **首页不再放搜索框**。`/search` 路由保留，直接访问 `/search?q=` 仍可用；
- 公开笔记详情页展示标签，点击标签跳转到 `/search?q=<tag 名>`（与 v1 一致）；
- 首页的「作品集 → 全部」跳 `/portfolio`；「近期笔记 → 全部」跳 `/notes`。

## 二、内容宽度（扩展 v1 `ui-design.md` 第二节）

- **公开域内容区宽度上限 960px**（v1 为 800px），水平居中，左右各留 24px 内边距；
- 窄屏（< 768px）时左右内边距降为 16px；
- **私有域布局不变**：左侧导航 240px / 中间列表 320px / 右侧内容区，阅读列宽仍为 800px。

## 三、首页结构

页面从上到下分为三段，横向分割线只出现在段与段之间（1px `var(--sep)`），段内依靠留白分层。

### 3.1 品牌区

```
正在做的事和写过的东西      ← 32px，字重 700，行高 1.25，letter-spacing -0.5px
一些项目和零散的记录。        ← 15px，灰色 var(--label-2)
```

- 上下留白：上 64px，下 40px；
- 文案固定为上面两句，写死在页面组件里；
- 不放搜索框、不放任何按钮。

### 3.2 作品集区

#### 区块标题行

```
作品集                                    全部 6 个 →
```

- 左侧标题：16px / 字重 600 / `var(--label)`；
- 右侧链接：13px / `var(--label-2)`，hover 时变 `var(--accent)`，带 `→` 后缀；
- **「全部 N 个 →」仅在 `total > 4` 时显示**；
- 标题行下边距 16px。

#### 卡片网格

- **宽屏（≥ 768px）双列**，`grid-template-columns: repeat(2, minmax(0, 1fr))`，列间距 16px、行间距 16px；
- **窄屏（< 768px）单列**；
- 首页**最多显示 4 个**作品（代码常量 `HOME_PORTFOLIO_LIMIT = 4`）。

#### 单张卡片

| 部位 | 规格 |
|---|---|
| 容器 | 背景 `var(--fill-3)`，1px `var(--sep)` 边框，圆角 12px，内边距 20px |
| 标题 | 17px / 字重 600 / `var(--label)` |
| 简介 | 14px / 行高 1.6 / `var(--label-2)`，最多 3 行，超出省略 |
| 仓库链接 | 12px 胶囊：背景 `var(--fill)`、圆角 999px、内边距 4px 10px，主链接用 `var(--accent)` 文字色 |
| hover | 边框色变 `var(--sep-strong)`，`transform: translateY(-2px)`，150ms 过渡 |

- **整张卡片链接到该作品的详情页** `/portfolio/:id`；如果没有仓库链接，只显示标题与简介；
- 卡片之间不做等高拉伸，按内容自然高度。

### 3.3 近期笔记区

#### 区块标题行

```
近期笔记                                    全部 12 篇 →
```

- 规格与作品集区块标题行一致；
- **「全部 N 篇 →」仅在 `total > 5` 时显示**；
- 跳转 `/notes`。

#### 笔记列表

- 首页**最多显示 5 篇**（代码常量 `HOME_NOTE_LIMIT = 5`）；
- 每篇之间间距 **24px**（v1 为 48px，因首页不再是列表主体而压缩）；
- 每篇的结构与 v1 一致：日期 → 标题 → 摘要（最多两行）；
- 字号：日期 13px `var(--label-2)`；标题 18px / 字重 700；摘要 14px / 行高 1.6 / `var(--label-2)`；
- hover 时标题变 `var(--accent)`。

### 3.4 空状态

| 区域 | 文案 |
|---|---|
| 作品集为空 | 「作品还在整理中」 |
| 笔记为空 | 「还没有公开的笔记」 |

- 只有作品集为空时，仍显示笔记区；反之亦然；
- 两块都为空时，整页显示一个空状态：「这里还空空的」。

## 四、笔记行规格（替换 v1 `ui-design.md` 第十节）

**本节替换 v1 第十节的间距与字号部分，其余规则（无分割线、摘要去 Markdown 符号、hover 变蓝）继续有效。**

| 项 | v1 | v3 |
|---|---|---|
| 行间距 | 48px | 首页 24px、`/notes` 页 32px |
| 标题字号 | 20px | 首页 18px、`/notes` 页 20px |
| 摘要 | 15px / 两行 | 14px / 两行 |
| 分割线 | 禁止 | 仍然禁止 |

## 五、`/notes` 页（新增）

- 页面标题：「公开笔记」，32px；
- 副标题：`共 N 篇公开笔记`；
- 列表：按 `published_at DESC`，每篇 32px 间距，样式同首页笔记区但字号回到 20px；
- **分页**：沿用「加载更多」按钮（v1 已有），不引入分页器；
- 顶部返回首页的路径由顶栏「笔记」导航承担。

## 六、作品详情页（新增）

**路径**：`/portfolio/:id`

| 部位 | 规格 |
|---|---|
| 返回链接 | 顶部「← 作品集」，指向 `/portfolio`，13px 灰色 |
| 标题 | 32px / 字重 700 / `var(--label)` |
| 简介 | 15px / `var(--label-2)`，取自 `description` |
| 仓库链接 | 沿用首页的胶囊样式，`is_primary` 用强调色 |
| 正文 | Markdown 渲染，复用 `renderMarkdown`（经 DOMPurify）；外层 `.md-body` |
| 空正文 | `content` 为空时显示「这个作品还没有写介绍。」 |
| 加载失败 / 不存在 | 显示空状态「找不到这个作品」 |

**规则**：

- 匿名可访问，无写操作入口；
- 首页的作品卡片、`/portfolio` 列表页的作品标题，都链接到本页；
- 正文只在详情接口返回，列表页拿不到，不缓存正文。

## 七、顶栏

在 v1 顶栏基础上：

- 导航项：`笔记`（跳 `/notes`）、`作品集`（跳 `/portfolio`）；
- **首页 logo 仍跳 `/`**；
- 不加搜索入口；
- 顶栏样式保持 v1 现状（细底边、无阴影）。

## 八、标签页（替换 v1 的 `/tags`）

**本节整节替换 v1 `frontend.md` 第四节中 `/tags` 那一行及其说明。**

标签页改为**只读展示**：不提供新建、删除、重命名。标签的创建与挂载只在编辑笔记页的 `TagDropdown` 完成。

### 8.1 布局

- 私有域单栏布局，**不使用中间列表栏**（路由只挂 `default` 组件）；
- 内容区顶部为标题「标签」与一句说明；
- 下方为**卡片网格**：`repeat(auto-fill, minmax(140px, 1fr))`，间距 12px，窄屏自动降列。

### 8.2 排序与分档

| 项 | 规则 |
|---|---|
| 排序 | 按 `note_count` 降序；次数相同时按标签名排序，保证顺序稳定 |
| 高频 | `note_count >= 10`：深色底 + 反白文字 |
| 中频 | `3 <= note_count < 10`：浅色底 + 实线边框 |
| 低频 | `note_count < 3`：极浅底 + 灰色文字 |

**阈值是代码常量**（`TIER_HIGH = 10`、`TIER_MID = 3`），调档只改常量，不改文档。

### 8.3 卡片内容

```
┌──────────────┐
│      Go      │  ← 标签名，15px / 字重 500 / 居中
│   12 篇笔记   │  ← 引用次数，12px / 次要色
└──────────────┘
```

- 卡片最小高度 88px，内容居中；
- hover：边框变深 + 上浮 2px，150ms 过渡；
- 点击卡片打开引用笔记窗口。

### 8.4 引用笔记窗口

- **居中弹窗**，宽度 `min(520px, 视口-32px)`，最大高度 `min(560px, 视口-96px)`；
- 标题为标签名，右上角关闭按钮；
- 内容为引用该标签的笔记列表：标题 + 「更新于 相对时间」；
- 点击笔记：**先关闭窗口，再跳转** `/notes/:id`；
- 点击外部或 `Esc` 关闭；
- 标签下没有笔记时，窗口内显示「这个标签下还没有笔记。」；
- 窗口内**不提供任何写操作**。

### 8.5 数据

| 时机 | 接口 |
|---|---|
| 进入页面 | `GET /api/tags`（一次，返回全部标签与 `note_count`） |
| 打开某个标签 | `GET /api/tags/:id/notes`（只取该标签的笔记） |

**不做聚合接口**：主页面只需一次请求，引用笔记按需加载。

### 8.6 空状态

没有任何标签时，整块显示「还没有标签 / 写笔记时在顶部「添加标签」，标签会出现在这里。」

## 九、明确不做

- 不做 RSS；
- 不做分页器（只保留「加载更多」）；
- 不做按标签浏览的独立页面（标签页只列出笔记标题，不提供筛选或分类浏览）；
- 不做上一篇 / 下一篇；
- 不做深色模式切换（沿用现有主题机制）；
- 不引入 UI 组件库、不引入动画库；
- 不做加载骨架屏的重新设计，沿用现有骨架屏。
