# frontend — 六期命令面板与快捷键

> 本文件回答：命令面板长什么样、怎么交互，以及全局快捷键清单。
> 依赖：`../v1/frontend/frontend.md`、`../api.md`

覆盖规则见 `../../README.md` 第二节。v1 的路由、全局状态、API 客户端约定继续有效。

## 一、命令面板

### 1.1 触发

| 操作 | 行为 |
|---|---|
| `Cmd+K`（macOS）/ `Ctrl+K`（其他） | **toggle**：未打开则打开，已打开则关闭 |
| `↑` / `↓` | 在结果中移动选中项 |
| `Enter` | 打开选中项 |
| `Esc` | 关闭 |
| 点击面板外部 | 关闭 |

- 打开时输入框自动聚焦，输入内容清空；
- 全站可用（私有域任意页面），公开域不启用。

### 1.2 布局

居中弹窗，宽度 `min(560px, calc(100vw - 32px))`，最大高度 `min(420px, calc(100svh - 160px))`，垂直位置靠上（距顶部约 15%）。

```
┌────────────────────────────────────────┐
│  🔍  搜索笔记或输入命令…                 │  ← 输入行，固定
├────────────────────────────────────────┤
│  笔记                                   │  ← 有输入时
│  📄 Haven 架构设计                      │
│  📄 Haven 部署说明                      │
│                                        │
│  命令                                   │  ← 无输入时
│  ✏️  新建笔记                           │
│  📊  打开仪表盘                          │
│  📁  打开工作台                          │
└────────────────────────────────────────┘
```

### 1.3 内容规则

**无输入**：只显示命令列表，固定三条：

| 命令 | 行为 |
|---|---|
| 新建笔记 | 跳转 `/notes/new` 并关闭面板 |
| 打开仪表盘 | 跳转 `/` 并关闭面板 |
| 打开工作台 | 跳转 `/notes` 并关闭面板 |

**有输入**：

- 调 `GET /api/search?q=<输入>&type=title&limit=20`，只取 `notes.items`，**忽略 `tags`**；
- 每条显示笔记标题，选中项高亮；
- 结果为空时显示「没有匹配的笔记」；
- **命令不参与匹配**：输入内容只搜笔记，不搜命令名。

### 1.4 交互细节

- **防抖 150ms**：连续输入只在停顿后发一次请求，代码常量；
- **竞态保护**：后发起的请求先返回时，不覆盖先发起但更晚返回的结果（按请求序号丢弃旧响应）；
- 从命令面板打开笔记：跳转 `/notes/:id` 并关闭面板；
- 面板打开时不改变页面滚动位置。

### 1.5 视觉规格

| 部位 | 规格 |
|---|---|
| 遮罩 | `var(--overlay)`，铺满视口 |
| 容器 | `var(--bg-elevated)`，圆角 12px，`var(--shadow-modal)` |
| 输入行 | 高 48px，无边框，底部 1px `var(--sep)` |
| 分组标题 | 12px / `var(--label-3)` / 大写间距 |
| 结果行 | 高 40px，圆角 8px；选中项背景 `var(--fill)` |
| 图标 | 16px，`var(--label-2)` |

## 二、全局快捷键

| 快捷键 | 行为 | 生效范围 |
|---|---|---|
| `Cmd/Ctrl+K` | 命令面板开 / 关 | 私有域全站 |
| `Cmd/Ctrl+S` | 立即保存当前笔记 | **仅编辑页** |
| `Cmd/Ctrl+N` | 新建笔记 | 私有域全站 |

**规则**：

1. **全部 `preventDefault()`**，劫持浏览器默认行为（保存网页、新建窗口）；
2. **`Cmd+S` 在编辑页**：取消正在等待的自动保存计时器，立即执行一次保存，并显示保存状态；
3. **`Cmd+S` 在非编辑页**：不拦截，也不做事（避免在搜索页按 Cmd+S 也弹保存提示）；
4. **输入框内不拦截 `Cmd+S` / `Cmd+N`**：焦点在 `input` / `textarea` / 内容可编辑区时，交给浏览器或编辑器处理——只有 `Cmd+K` 在任何状态下都拦截；
5. **公开域不启用任何快捷键**。

## 三、不做的事

- 不做可配置键位；
- 不做 `Cmd+P`（与浏览器打印冲突）；
- 不做编辑器内的 Vim / Emacs 键位；
- 不做命令历史、最近使用排序；
- 不做模糊匹配打分。
