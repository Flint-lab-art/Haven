# conventions — 六期约定

> 本文件回答：六期相对前几期约定做了哪些补充。
> 依赖：`../v1/conventions.md`

覆盖规则见 `../README.md` 第二节。v1 第一至五节继续有效，本文件只写六期新增。

## 一、六期约定补充

1. **命令面板是唯一的新增全局入口**：不改变现有侧边栏、列表栏的布局与导航。
2. **命令面板只做两件事**：打开笔记、执行固定命令。不做参数化命令（如「移动到文件夹 X」）。
3. **命令列表固定为三条**：新建笔记、打开仪表盘、打开工作台。**不接受运行时注册**。
4. **搜索走服务端**：输入时调 `GET /api/search?type=title`，不在前端拉全量笔记过滤。
5. **搜索防抖 150ms**：避免每敲一个字发一次请求，这是代码常量。
6. **允许引入 `@milkdown/components` 的列表项组件**：只为任务列表复选框服务（`v6/frontend/frontend.md` 第五节）。这是对 `v1/conventions.md` 第六节「引入第三方 UI 组件库须经维护者同意」的一次授权，不构成对其它组件库的默许；引入其它库仍需逐次同意。
7. **编辑器内只允许两类可点控件**：任务列表的方块（第五节）、代码块的复制按钮（第六节）。除此之外不出现按钮、Toolbar、浮层。（命令面板属于全站层，不在编辑器内。）

## 二、禁令变更

### 2.1 放宽的约束

| 条目 | 六期处理 |
|---|---|
| 浏览器默认快捷键不被劫持（隐含约定） | **允许劫持** `Cmd/Ctrl+S`、`Cmd/Ctrl+N`、`Cmd/Ctrl+K`，并 `preventDefault()`。理由：单人自用工具，符合编辑器类应用的习惯 |

### 2.2 仍然有效的禁令

- 不做可配置键位；
- 不做命令注册机制或插件式命令；
- 命令面板不做模糊匹配打分（只做 `ILIKE` 子串匹配）；
- 不在命令面板内做写操作（新建笔记是跳转到编辑页，不是直接创建）。
