# ui-design — 界面与交互设计规范

> 本文件回答：前端的整体布局形态、色彩排版系统、组件规范与交互反馈。
> 依赖：无

## 一、设计原则

1. **专注阅读**：作为知识中台，界面必须保证长文阅读和长时间写作的舒适度。
2. **信息密度与留白**：摒弃大而无当的卡片，采用紧凑且清晰的列表结构；给内容区留出足够的呼吸空间。
3. **克制与克制**：减少不必要的边框、阴影、大面积色块和动画，用间距和对齐来区分层级。

## 二、整体布局（桌面端三栏式）

私有域后台放弃“顶部导航+居中卡片”的单列布局，统一采用经典的**三栏式应用布局**（类似 macOS 备忘录、Notion、Obsidian）：

| 区域 | 宽度 | 背景色 | 职责 |
|---|---|---|---|
| **左侧导航栏** | 固定 `240px` | 浅灰 `#F7F7F9` | 全局功能入口（Logo、搜索、笔记、标签、作品集、设置、用户信息） |
| **中间列表栏** | 固定 `320px` | 纯白 `#FFFFFF` | 当前分类下的条目列表（新建按钮、过滤器、笔记列表） |
| **右侧详情/编辑区** | 自适应剩余宽度 | 纯白 `#FFFFFF` | 笔记阅读与编辑，内容区居中且限制最大宽度。 |

**规则**：
- 右侧内容区必须设置 `max-width: 800px` 且水平居中，避免宽屏下视线横向移动距离过长。
- 左右三栏之间的分割使用极细的 `1px` 边框（`#E5E5EA`），不使用阴影。

## 三、色彩与排版系统

### 3.1 色彩规范
- **主背景**：纯白 `#FFFFFF`。
- **主文字**：深灰 `#1A1A1A`（避免纯黑造成视觉疲劳）。
- **次要文字**（时间、摘要、占位符）：`#8E8E93`。
- **强调色**（主按钮、选中状态）：蓝色 `#007AFF`。
- **分割线**：`#E5E5EA`。

### 3.2 排版规范（可阅读性的核心）
- **UI 字体**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", sans-serif`。
- **正文字体**：优先无衬线字体，字号 `16px` 或 `17px`。
- **行高**：正文严格设为 `1.7`；标题设为 `1.3`。
- **字号层级**：H1 `32px`，H2 `24px`，H3 `20px`，正文 `16px`。
- **段落间距**：段落之间保留 `1em` 的 margin。

## 四、组件规范

### 4.1 列表项（List Item）
- **外观**：平铺列表行，不使用浮动卡片。
- **内容**：标题（加粗）、纯文本摘要（截断 80 字，灰色）、底部显示更新时间与可见性图标。
- **状态**：
  - `hover`：背景变浅灰 `#F2F2F7`。
  - `active`（当前选中）：背景变极浅蓝 `#E5F0FF`，左侧边缘出现 `3px` 蓝色指示条。
- **可见性图标**：私有显示灰色锁形图标，公开显示蓝色地球图标，放置在标题右侧，大小不超过 `14px`。

### 4.2 按钮（Button）
- **主按钮**（如“新建笔记”）：背景 `#007AFF`，纯白文字，圆角 `8px`，无边框，`hover` 时背景微暗。
- **次按钮**（如“取消”）：透明背景，灰色文字，`hover` 时背景变浅灰。
- **图标按钮**：只包含图标，`hover` 时显示浅灰底色圆形。

### 4.3 输入框（Input / Textarea）
- 默认无边框，背景透明或极浅灰。
- `focus` 状态：底部出现 `2px` 蓝色线条，或外圈出现极淡的蓝色晕染。

### 4.4 标签胶囊（Tag Badge）
- 浅灰背景 `#F2F2F7`，深灰文字。
- 圆角 `6px`，字号 `12px`。
- 不使用鲜艳背景色，不使用大色块。

## 五、交互与状态反馈

1. **路由切换无刷新**：从列表点击笔记时，仅右侧详情区内容更新，左侧和中间栏保持不动。
2. **键盘友好**：列表栏支持上下方向键切换笔记，选中后右侧直接展示。
3. **空状态**：列表为空时，显示极简的灰色插画或文字提示，配一个主按钮引导创建。
4. **加载状态**：使用极细的顶部进度条或骨架屏（Skeleton），不使用转圈圈的 Loading 图标。

## 六、已知不做
- 不做深色模式（第二版再考虑）。
- 不做复杂的动画过渡（保持干脆利落的响应）。
- 默认手写 CSS；如需引入第三方 UI 组件库或 Emoji Picker，必须事先经过项目维护者同意，并优先选择体积小、维护活跃、与 Vue 3 兼容的方案。

### 7.5 Milkdown 编辑器专属配置（必须遵守）

项目使用 `@milkdown/vue` 作为核心编辑器，需严格按以下规范剥离默认样式，实现“无边框、沉浸式”体验：

1. **彻底去边框与轮廓（Reset）**：
   - 必须编写全局 CSS，强制去除 Milkdown 容器（`.milkdown` 或 `.ProseMirror`）的所有 `border`、`outline`、`box-shadow` 和 `background-color`。
   - 确保点击正文进入输入状态时，没有任何蓝色或灰色的外框。
2. **去除多余 UI**：
   - 不渲染 Milkdown 自带的顶部 Toolbar 或菜单栏。
   - 只保留纯净的输入区和滚动条。
3. **排版样式覆盖**：
   - 虽然是无边框容器，但在 CSS 中必须为 `.ProseMirror` 内部的 `h1`, `h2`, `p`, `ul`, `li` 等标签指定我们自己的排版规范（正文 16px，行高 1.7，段落间距等），以覆盖浏览器默认样式。
4. **自动保存与状态反馈**：
   - **取消底部的“保存”和“取消”按钮**。
   - 使用 `@milkdown/plugin-listener` 监听 `markdownUpdated` 事件，实现防抖（Debounce 1000ms）自动保存。
   - 在编辑器顶部（或右上角）显示轻量级的文字状态：`正在保存...` / `已保存`，不要打断用户的输入心流。
5. **顶部操作区布局**：
   - 标题输入框（`test`）和下方的正文编辑器，应通过 CSS 放置在同一个无边框的容器中，视觉上是一体的。
   - 标签管理、公开/私有切换、删除按钮，做成极简的小图标或文字按钮，统一放置在页面的右上角，与正文区域拉开层级。

### 7.6 大纲（Outline）
- 笔记编辑页在 800px 正文列右侧的留白中显示当前笔记的标题目录（H1–H3）。
- 点击条目滚动到对应标题；滚动正文时高亮当前所在章节。
- 没有标题时不显示；窗口宽度不足时自动隐藏，不挤压正文宽度。

## 八、侧边栏结构、设置合并与 Mini 模式

### 8.1 整体结构与“设置”合并
- **去除中间设置项**：左侧导航区只保留全局功能（笔记、搜索、标签、作品集）。**移除中间独立的一级菜单“设置”**。
- **底部用户中心**：侧边栏最底部固定为“用户信息区”，包含圆形头像、用户名（kairo）、空间名（个人空间）。
- **弹出菜单**：点击底部的用户信息区，向上弹出下拉菜单，菜单内包含：**“设置”** 和 **“退出登录”**。这样彻底解决中间排版散乱的问题。

### 8.2 Mini 模式折叠交互
- **触发方式**：在侧边栏顶部（Logo 右侧）提供一个折叠按钮（如双箭头图标）。
- **形态变化**：点击折叠后，侧边栏宽度从 `240px` 平滑过渡收缩至 `64px`。
- **内容隐藏**：文字标签（导航名称、Logo 文字、用户信息文字）全部隐藏，图标保持居中。
- **悬浮提示（Tooltip）**：鼠标悬浮在导航图标上时，必须弹出黑底白字的 Tooltip 显示功能名（如“笔记”、“设置”）。
- **Mini 模式下的底部**：折叠后，底部仅显示居中的圆形头像。点击头像依然能向上弹出包含“设置、退出”的下拉菜单。

### 8.3 状态持久化
- 侧边栏的折叠状态必须保存在 `localStorage` 中，刷新页面后保持用户的偏好。

### 8.4 右侧空状态
- 未选中笔记时，右侧详情区保持极简留白。仅在中央显示极淡的占位文字或图标，不添加复杂面板。

## 九、中间列表栏（List Pane）的树状目录结构

中间列表栏不再仅展示平铺笔记，而是采用“文件夹树”的结构（类似思源笔记、Obsidian），以承载无限嵌套的目录。

### 9.1 布局与树状渲染
- **顶部操作区**：左侧显示当前目录名，默认“收件箱”，字号 `16px`、加粗；右侧提供“新建笔记”和“新建文件夹”两个图标按钮。中间列表栏底部不再固定“新建笔记 / 新建文件夹”按钮。
- **收件箱节点**：收件箱是真实文件夹（`is_inbox = true`），固定在根目录第一位；默认名“收件箱”，允许改名和更换图标，不可删除、不可移动。
- **树内笔记**：笔记挂在所属文件夹或收件箱下方，与文件夹混排在同一棵树内；不单独拆出笔记列表，也不做“全部笔记 / 最近笔记”独立视图。
- **默认选中**：默认选中收件箱；新建笔记落到当前选中的目录。
- **递归组件**：前端需实现一个递归的 `TreeNode` 组件。每个文件夹前面有展开/折叠的 `v` 箭头。
- **缩进层级**：子文件夹通过左侧缩进（每级 `16px`）体现层级。
- **图标**：文件夹有 `icon` 时直接渲染 Emoji，否则使用默认 Folder 线条图标；笔记使用 FileText 图标。点击文件夹图标本身打开“更改图标”面板，点击文件夹名称仍然选中/展开文件夹。

### 9.2 交互逻辑
- **点击文件夹**：高亮该文件夹，展开显示其直属笔记。
- **折叠/展开**：点击箭头折叠子层级。
- **右键菜单（普通文件夹）**：`新建子文件夹`、`重命名`、`更改图标`、`删除`。
- **右键菜单（收件箱）**：`新建子文件夹`、`重命名`、`更改图标`；不显示“删除”。
- **文件夹拖拽**：普通文件夹支持同层上下排序、拖入/拖出父级、拖回根目录；收件箱不可拖动，但可以作为拖放目标。收件箱固定根目录第一位，其他根级文件夹在它之后排序；禁止拖入自身或自己的子文件夹。
- **删除普通文件夹**：先把该文件夹及子文件夹内的所有笔记移到收件箱，再删除文件夹；收件箱不可删除。
- **笔记拖拽**：支持拖到其他文件夹或收件箱；在同一目录内支持上下拖拽排序。
- **拖拽持久化**：同一目录拖拽后，把该目录下的兄弟项重新编号为 `0..n-1`，只提交发生变化的项；文件夹跨层同时提交 `parent_id`，笔记跨层同时提交 `folder_id`。笔记移入新目录时 `sort_order` 置 `0`，出现在目录顶部。
- **图标面板**：点击文件夹图标或菜单“更改图标”打开；内置常用 Emoji、手动输入、恢复默认；点击外部或按 `Esc` 关闭。


**公开域笔记列表排版规范**

1. **去除边界感**：笔记列表项（Note Item）之间**禁止使用任何分割线（border-bottom）**。完全依靠留白来区分内容。
2. **上下间距**：每个笔记项之间的垂直间距（margin-bottom）必须大于 `40px`。
3. **排版顺序**：
   - 顶部：发布日期（字号 `13px`，颜色 `#8E8E93`，格式如 `2026年10月29日`）。
   - 中部：标题（字号 `20px`，粗体，颜色 `#1A1A1A`，上边距 `8px`）。
   - 底部：摘要（字号 `15px`，颜色 `#8E8E93`，行高 `1.6`，最多显示两行，超出用 `...` 截断）。
4. **交互反馈**：鼠标悬浮在某一篇笔记上时，标题颜色变为蓝色（`#007AFF`），鼠标指针变为手型。
5. **摘要清理**：在渲染摘要前，必须使用正则去除 Markdown 符号（如 `#`、`*`、`>`）。
